# REQUIREMENTS.md

## 1. Functional Requirements

### Core
- User registration & login (email + Google preferred)
- Select / switch College + City
- Location-based discovery (nearby first)
- Search + Filters across all modules
- User profiles with verification badge (college email)

### Modules
1. **Stay** – PG, Hostel, Flat, Roommate finder
2. **Food** – Tiffin services, Mess, Affordable restaurants
3. **Jobs & Internships** – Part-time, full-time, internships
4. **Marketplace** – Buy / Sell / Exchange books, notes, gadgets, furniture
5. **Resources** – Notes, Previous Year Question Papers, Reference books, Libraries
6. **Services** – Laundry, Xerox/Stationary, Internet Café, Computer Centers
7. **Events** – Workshops, Hackathons, Tech talks, College fests
8. **Health** – Medical stores, Hospitals, Clinics
9. **Skills & Career** – Courses, Resume builder, Skill tracks

### Social / Community
- Ratings & Reviews
- Report listing
- Favorite / Save
- Basic messaging (for marketplace & roommate)

## 2. Non-Functional Requirements
- Mobile responsive (priority)
- Fast load times (< 2s on 4G)
- SEO friendly for public pages
- Secure (auth, input validation, rate limiting)
- Scalable to multiple cities
- Accessibility (WCAG AA target)

## 3. User Roles
- Student (default)
- Listing Owner / Service Provider
- Admin / Moderator
- College Ambassador (optional later)
