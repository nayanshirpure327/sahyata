# FEATURES.md

## MVP Features (Phase 1)

### 1. Authentication & Onboarding
- [ ] Sign up / Login (Email + Google)
- [ ] Select City + College
- [ ] Basic profile (name, year, course, phone optional)

### 2. Explore
- [ ] Category grid (Stay, Food, Jobs, Marketplace, Resources, Services, Events, Health, Skills)
- [ ] Map view + List view
- [ ] “Near me” sorting
- [ ] Search bar

### 3. Stay (PG / Hostel)
- [ ] List PGs with price, gender, food, distance, photos
- [ ] Filters: Budget, Gender, Food included, AC/Non-AC
- [ ] Detail page + Contact / WhatsApp

### 4. Food
- [ ] Tiffin services (daily/weekly plans)
- [ ] Affordable mess & restaurants
- [ ] Filters: Vegetarian, Price range, Delivery

### 5. Jobs & Internships
- [ ] Job listings with type (Part-time / Internship / Full-time)
- [ ] Apply / Save
- [ ] Company / Poster details

### 6. Marketplace
- [ ] Post item (Book, Notes, Gadget, Furniture, Other)
- [ ] Buy / Sell / Exchange tags
- [ ] Chat or contact seller

### 7. Resources
- [ ] Upload / Browse Notes & PYQs
- [ ] Second-hand books
- [ ] Library listings
